# Yaseen Badshah — Portfolio Website

Personal portfolio site for Yaseen Badshah, AI Video Creator & Digital Marketer.

## What's inside
- `index.html` — the complete single-page site (all CSS & JS inline, no build step, no dependencies)

## Sections
Hero · Services · Selected Work (TikTok portfolio + 5 LinkedIn ad concepts) · About · Certifications · Contact

## Run it locally
Just open `index.html` in a browser — or serve the folder:
```bash
python3 -m http.server 8000
```
then visit http://localhost:8000

## Deploy free with GitHub Pages
Repo Settings → Pages → Deploy from branch → `main` / root. The site goes live at
`https://<username>.github.io/portfolio-website/`
